# Emotion Detection Application

## Project Name
Emotion Detection Application using Watson NLP and Flask

## Description
A Python web application that detects emotions in text
using the Watson NLP emotion prediction service and Flask.

## Technologies
- Python 3
- Watson NLP
- Flask
- unittest
- Pylint

## Features
- Emotion detection
- Dominant emotion identification
- Input validation and error handling
- Unit testing
- Flask web interface
